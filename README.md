Тема проекта: "Разработка ИИ-ассистента, обогащающего пользовательские запросы экспертными знаниями на основе онтологической модели"
# Общая идея проекта
Проект предполагает создание прототипа приложения с интеллектуальным ассистентом, использующим онтологию в качестве базы знаний. Онтология формируется на основе экспертных данных выбранной предметной области и служит основой для корректного понимания структуры пользовательских запросов.
Разрабатываемый ассистент должен помогать пользователям, не обладающим опытом в конкретной сфере, уточнять запросы, дополнять их недостающими параметрами и преобразовывать в корректную формулировку для передачи специалисту.
