# Отчет по лабораторной работе №5
**Тема:** Реализация микросервисной архитектуры на основе контейнеров Docker

## 1. Архитектура системы
Согласно диаграмме контейнеров, приложение было разделено на 3 независимых сервиса:

1.  app-server: Реализован на FastAPI. Содержит бизнес-логику анализа запросов и взаимодействия с онтологией.
2.  ontology-db: СУБД PostgreSQL. Используется для хранения структурированных данных и имитации графового хранилища онтологии.
3.  web-client-test: Легковесный контейнер на базе `curl`, который имитирует запросы клиента и выполняет автоматизированное тестирование системы после её запуска.

## 2. Интеграционные тесты
В системе реализованы автоматические интеграционные тесты (контейнер web-client-test). Сценарий тестирования:
1. Ожидание запуска сервера (`sleep`).
2. Проверка сетевого соединения сервера с базой данных (эндпоинт `/v1/db-check`).
3. Проверка корректности обработки POST-запроса на анализ текста.

## 4. Непрерывная интеграция (CI)
Настроен GitHub Actions (docker-ci.yml). При каждом пуше в ветку автоматически запускается процесс сборки Docker-образов.

## Результаты работы
В ходе работы была реализована микросервисная архитектура, настроено взаимодействие между контейнерами через внутреннюю сеть Docker и автоматизировано тестирование процесса развертывания.
